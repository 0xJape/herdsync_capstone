# HerdSync Reports

## Required reports
- Active cattle inventory
- Individual cattle profile
- Health and assessment history
- Treatment and vaccination history
- Withdrawal status
- Breeding outcomes
- Pregnancy and expected delivery
- Birth and offspring lineage
- Mortality, sold, culled, and archived cattle
- Farm activity
- User activity and audit logs

## Report behavior
- Filter by date, status, breed, sex, age class, and cattle ID where relevant.
- Enforce role permissions before query and export.
- Show generated timestamp, filters, totals, and responsible user.
- Support print and CSV first; add PDF after template approval.
- Use tables and text alternatives for chart data.
