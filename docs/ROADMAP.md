# HerdSync Roadmap

## MVP
Authentication, roles, cattle inventory, profiles, health assessments, treatment/vaccination, withdrawal warnings, breeding, pregnancy, birth, alerts, audit logs, CSV/print reports, responsive interface.

## Phase 2
PDF templates, attachments, richer charts, batch operations, configurable farm schedules, email notifications, offline evaluation.

## Future
QR identification, RFID, IoT sensors, GPS, automated weighing, predictive analytics, mobile app, multi-farm support, approved external integrations.

Never allow future features to weaken baseline data integrity, authorization, or veterinary safeguards.
