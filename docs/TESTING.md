# HerdSync Testing

## Unit
Test date calculations, gestation stages, withdrawal periods, statuses, validation, and permission checks.

## Integration
Test cattle-to-treatment-to-alert, breeding-to-pregnancy, pregnancy-to-birth, offspring links, transactions, reports, and audit entries.

## UI and responsive
Test Chrome, Edge, Firefox, and Safari where applicable. Test phone, tablet, and desktop layouts. Check no clipped cards, broken padding, overflow, or inaccessible controls.

## Accessibility
Check labels, keyboard navigation, focus states, contrast, touch targets, icon names, reduced motion, and non-color status signals.

## Acceptance
Use realistic cattle data. Verify each minimum acceptance criterion in `HERDSYNC_PROJECT_OVERVIEW.md` before release.
